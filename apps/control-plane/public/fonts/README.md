# Geist fonts

Geist Sans and Geist Mono are the typefaces specified by the Zuvel brand manual.
These Latin WOFF2 assets were copied without modification from the installed
Next.js package (`next/dist/next-devtools/server/font/geist-latin.woff2` and
`geist-mono-latin.woff2`). They are served locally; the UI does not request fonts
from an external service.

Upstream: https://github.com/vercel/geist-font
